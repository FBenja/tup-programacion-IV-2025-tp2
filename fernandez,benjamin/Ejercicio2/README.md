# Ejercicio 2

Desarrollar una API con ExpressJS de un listado de tareas completadas o por
completar. Guardar el nombre de la tarea y si fue completada o no en una base
de datos MySQL. Verificar en la API al momento de crear que no se repitan
tareas con el mismo nombre. Agregar un filtro que devuelva tareas completadas o
por completar.
