# Ejercicio 3

Realizar una API con ExpressJS que gestione el listado de alumnos de una carrera.
Guardar el nombre del alumno, la materia y tres notas en una base de datos MySQL.
Verificar en la API al momento de crear/modificar que no se repitan alumnos con
el mismo nombre y materia. Para las materias emplear una tabla aparte relacionada
a la tabla de alumnos.
